# 그림자 복도 구역 랜더마이저 (비공식 MOD)

Steam 게임 「그림자 복도(Shadow Corridor)」의 구역을 섞어 새 맵을 만드는 무료 비공식 MOD입니다.

- 제작자(Space Onigiri Game)의 공식 제품이 아닙니다. 제작자의 답변에 따라 무료 MOD 배포는 허용되며 유료 판매는 허용되지 않습니다.
- 수정하지 않은 게임 원본 자료는 들어 있지 않습니다. 필요한 원본 자료는 사용자가 설치한 게임에서 읽어 준비합니다.

## 받기와 업데이트
- 판마다 Releases에 올립니다.
- 처음 받는 분: 전체 배포본(…-with-answer-key.zip)이 있는 가장 최근 판을 받아 압축을 풀고 「사용 방법.txt」를 보세요.
- 이미 쓰는 분: 0.35.0부터는 앱의 「업데이트」 탭에서 「최신 판 확인」 → 「업데이트」를 누르면 됩니다.
  그 전 판은 업데이트 파일(…-update.zip)을 앱 폴더 안에 풀고 「업데이트 적용.cmd」를 한 번 실행하세요.
