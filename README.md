# 그림자 복도 구역 랜더마이저 (비공식 MOD)

Steam 게임 「그림자 복도(影廊 -Shadow Corridor-)」용 **무료 비공식 MOD**입니다.
매미의 복도·심연·영혼 집합소·성역의 구역을 섞어 새 맵을 만들고, 버튼 하나로 게임에 넣거나 원래대로 되돌립니다.
더 어려운 난이도 **「초월자」** 와 네 스테이지를 이어서 달리는 **「마라톤」** 도 들어 있습니다.

- 제작자(Space Onigiri Game)의 공식 제품이 아닙니다. 제작자의 답변에 따라 무료 MOD 배포는 허용되며 유료 판매는 허용되지 않습니다.
- 수정하지 않은 게임 원본 자료는 들어 있지 않습니다. 필요한 원본 자료는 사용자가 설치한 게임에서 읽어 준비합니다.

## 할 수 있는 것

| 앱의 탭 | 내용 |
|---|---|
| 맵 랜더마이저 | 네 스테이지의 구역을 섞어 새 맵 만들기, 같은 구역 여러 번 놓기, 벽·바닥 스타일, 맵 공유 코드 |
| 곡옥 색깔 | 초록(기본)·무지개·파랑·청백·빨강·검정 |
| 난이도 선택 | 초월자 난이도, 마라톤 모드 |
| 해가 뜬 복도 | 조명: 원래 조명·구버전 조명·맑은 낮·붉은 노을·푸른 새벽·달빛 밤 |
| 업데이트 | 새 판 확인, 버튼 하나로 업데이트 |

앱 글자는 한국어·English·日本語 중에서 고를 수 있습니다(창 오른쪽 위 「언어」).

## 맵 랜더마이저

- 기본 스테이지(매미의 복도·심연·영혼 집합소·성역)를 고르면, 그 스테이지의 갈림길 구역 자리에 네 스테이지의 구역을 섞어 넣습니다.
  - 4갈래 자리: 매미의 복도·성역 11곳, 심연·영혼 집합소 10곳. 2갈래 4곳, 3갈래 10곳.
  - 시작·출구와 맵 전체 설정은 기본 스테이지 그대로입니다.
- 고정 구역: 원하는 구역은 고정하고 나머지만 섞을 수 있습니다.
- 중복 배치: 같은 구역을 여러 자리에 놓을 수 있습니다(예: 영혼 집합소 X5를 3곳). 영혼 집합소 X6은 반복할 수 없습니다.
- 맵 스타일: 벽·벽지·바닥 재질을 원본(구역별)·매미의 복도·심연·영혼 집합소·성역 중에서 고릅니다. 모양·충돌·이벤트는 그대로입니다.
- 네 스테이지의 맵을 각각 만들어 한 번에 함께 적용할 수 있습니다.
- 맵 공유 코드(SCR1-…): 만든 맵의 구성을 짧은 코드로 주고받습니다. 같은 판이면 똑같은 맵이 만들어집니다.
- 프리셋: 자주 쓰는 구성을 이름을 붙여 저장합니다.
- 맵 4장을 만드는 데 1분 안팎 걸립니다(PC 사양에 따라 다름).

## 초월자 난이도

이 MOD가 만든 더 어려운 난이도입니다. 앱에서 초월자를 적용하면 게임의 **「도전자」 난이도 자리**에 들어갑니다.
게임에서 도전자를 고르면 초월자로 플레이합니다. 초보자·파괴자·곡옥 챌린지는 원래대로입니다.

| 스테이지 | 주요 변경 |
|---|---|
| 매미의 복도 | 무녀 4 → 6마리, 달배 1 → 2마리, 무녀 배회 속도 2배, 제단·황금곡옥에서 도코니 추가 소환 |
| 심연 | 달배 2·거미 5·배회 도코니 5마리, 달배 추격 속도 400, 검붉은 복장, 거미 접근 경고 없음, 곡옥 5개면 증원과 출구 살기, 출구에 고정 도코니 |
| 대식가 | 화면을 어둡게, 검붉은 조명(세기·등불 반경 30%), 2페이즈 길 안내 방울 없음 |
| 영혼 집합소 | 무녀 4·달배 2·배회 도코니 6·경종 4마리, 무녀 속도 500·달배 600, 남색 복장, 출구에 고정 도코니, 곡옥 검은 연기, 살기는 황금곡옥으로 나타남(방에 들어가면 빨간 살기, 주우면 검은 살기) |
| 성역 | 천리안 6·무녀 6·달배 3마리, 흰색 복장, 제단에 고정 도코니, 곡옥을 모을수록 수위가 3단계로 오름(3~4개면 물에 닿을 때 스태미나 회복 절반, 5개면 회복 없음), 물속 시야 흐림·이동 느려짐, 배수 레버로 풀림 |
| 해후 | 금붕어부터 시작, 사미호 전투 1.5배 빠르게, 석등 없음, 6~8페이즈 새 패턴(시선 사냥·잔상 교차사격·일식·나선 핀볼과 메테오) |
| 시체가 흐르는 계곡·방대해진 증오 | 변경 없음 |

- 심연·영혼 집합소·성역의 도코니는 문을 1~2초 만에 부수고, 목소리가 멀리까지 들립니다.
- 전체 목록은 앱의 난이도 탭 「자세한 구성 보기」에 있습니다.
- 랜더마이저 맵은 초월자·도전자 어느 쪽으로도 만들 수 있습니다.

## 마라톤 모드

네 스테이지를 이어서 달리는 타임 어택입니다.

1. 앱의 난이도 탭에서 「마라톤 모드」를 켜고 「현재 맵에 난이도 설정 적용」을 누릅니다(게임은 끈 상태).
2. 게임 타이틀 첫 화면의 「부가 메뉴」(게임 종료 위) → 「마라톤」 → 종류를 고릅니다.

- 순서: 매미의 복도 → 심연 → 영혼 집합소 → 성역. 결과 화면 뒤 바로 다음 맵으로 넘어갑니다(추격전 등 고정 스테이지는 건너뜀).
- 이어지는 것: 들고 있는 물건·열쇠·폭죽·야광석·카메라·장착 아이템·황금 곡옥, 체력과 손전등 배터리, 그리고 시간(결과 화면 = 누적 시간).
  - 체력은 저절로 차지 않습니다(일부 장착 아이템을 찼을 때만 천천히 참). 배터리는 손전등을 켠 동안만 줄고, 맵에서 손전등을 주우면 가득 찹니다.
- 심연 시작 때 수정구슬을 자동으로 주지 않습니다(놓인 구슬은 주울 수 있음).
- 죽고 「다시 하기」를 고르면 매미의 복도부터 다시 시작합니다(아이템·시간·체력·배터리도 처음부터). 타이틀로 돌아가면 마라톤이 끝납니다.
- 고를 수 있는 종류는 앱에서 적용해 둔 것에 따라 정해집니다.
  - 초월자: 초월자 + 기본 맵
  - 도전자·파괴자: 도전자 + 원본 맵(파괴자는 게임에서 파괴자를 연 뒤)
  - 랜더마이저: 랜더마이저 맵(초월자·도전자 기록 따로)
- 기록: 성역까지 깨면 누적 시간이 최고 기록보다 빠를 때 저장됩니다. 초월자·도전자·파괴자·랜더마이저 (초월자)·랜더마이저 (도전자) 다섯 칸입니다.
  - 아이템 무한·금메달·텐코 가면을 쓴 판은 저장하지 않습니다. 마라톤 중에는 맵별 일반 기록을 남기지 않습니다.
  - 「기록 지우기」에서 하나씩 또는 전체를 지울 수 있습니다.
- 같은 랜더마이저 맵으로 기록을 겨루려면 맵 공유 코드를 쓰세요.
- 「부가 메뉴」 글자는 게임 언어(日本語·English·한국어)를 따릅니다.

## 받기와 설치

[Releases](https://github.com/dssfdsf49-ship-it/ShadowCorridor-Randomizer/releases)에서 받습니다.

- `…-with-answer-key.zip`: 처음 받는 분용 전체 배포본. 이름의 with-answer-key는 맵을 빨리 만들 때 검사에 쓰는 자료가 함께 들어 있다는 뜻입니다.
- `…-update.zip`: 이미 쓰는 분용 업데이트 파일.
- 처음 받는 분 바로가기: v0.35.0 전체 배포본 → https://github.com/dssfdsf49-ship-it/ShadowCorridor-Randomizer/releases/tag/v0.35.0 (받은 뒤 앱의 「업데이트」 탭으로 최신 판까지)

필요한 것: Windows 10·11(64비트), Steam판 그림자 복도, 여유 공간 20GB 이상. Python·.NET은 따로 설치하지 않아도 됩니다. DLC 외연은 지원하지 않습니다.

1. 압축을 짧은 경로의 쓰기 가능한 폴더(바탕 화면·문서 등)에 모두 풉니다. 압축 안에서 바로 실행하지 마세요.
2. `실행.cmd` → 게임 설치 폴더 선택 → 「준비하고 실행」. 첫 준비는 약 8분 걸립니다.
3. 맵 랜더마이저 탭에서 기본 스테이지·스타일·구역을 고르고 ① 현재 설정 담기 → ② 대기열 생성 → ③ 체크한 맵 모두 적용(게임은 끈 상태).
4. Steam에서 게임을 켜고, 고른 기본 스테이지에 도전자 난이도로 들어갑니다.
5. 원래대로 돌리려면 「원본 맵으로 복원」을 누릅니다. 적용할 때 세이브(Saved)를 백업하고, 원본 게임 파일은 덮어쓰지 않습니다.

## 업데이트

- 0.35.0부터: 앱의 「업데이트」 탭 → 「최신 판 확인」 → 「업데이트」. 바뀐 파일만 받아 바꾸고 앱이 다시 켜집니다. 만든 맵·설정과 게임 폴더는 그대로입니다.
- 0.33.0~0.34.x: 최신 릴리스의 `…-update.zip`을 앱 폴더 안에 풀고 「업데이트 적용.cmd」를 한 번 실행하세요. 그다음부터는 「업데이트」 탭을 씁니다.
- 그보다 예전 판: 전체 배포본을 새 폴더에 풀어 쓰세요.

## 알아 둘 것

- 적용·복원할 때는 게임을 끄세요(Steam은 켜 둬도 됨). 앱은 게임이나 Steam을 자동으로 켜지 않습니다.
- 다른 MOD Pak이 있으면 적용을 멈춥니다(그림자복도 유틸리티의 곡옥 색 Pak은 함께 쓸 수 있음).
- 게임이 업데이트되면 랜더마이저도 새 판이 필요할 수 있습니다.
- 파일·생성·설치 검사를 거치지만, 모든 구역 조합의 실제 플레이를 확인한 것은 아닙니다. 문제가 생기면 「원본 맵으로 복원」을 누르세요.
- 영상·방송·다른 곳에 올리는 것은 자유이지만, 비공식 MOD임을 표시하고 무료로만 배포해 주세요.
- 제3자 프로그램의 라이선스는 배포본의 `licenses` 폴더 등에 있습니다(UAssetAPI·UAssetGUI·SCU-Randomizer·ZstdSharp·Python·.NET·repak).
